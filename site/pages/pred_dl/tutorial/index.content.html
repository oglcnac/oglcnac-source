Preparing FASTA input

O-GlcNAcPRED-DL tutorial

Select the appropriate species, provide complete FASTA records, and interpret the resulting site scores.

1. Select human or mouse

  • Choose the species from which the proteins were obtained because a different model was developed for each species.
  • Prediction for proteins from other species is technically possible, but the results should be used with extra caution.

2. Provide protein sequences in FASTA format

  • Paste a single sequence or upload a FASTA file containing multiple protein sequences.
  • Protein sequences can be up to 8,000 amino acids.
  • Each sequence must include a FASTA header.

Download examples for an individual human protein, an individual mouse protein, multiple human proteins, or multiple mouse proteins.

3. Submit for prediction

  • An individual protein usually takes several seconds to process.
  • A FASTA file containing multiple protein sequences may take longer.
  • Prediction runs locally in the browser; keep the page open until it completes.

4. Interpret and export results

  • A prediction score is reported for every serine or threonine residue.
  • Scores greater than 0.5, 0.95, and 0.99 can be regarded as low, medium, and high confidence, respectively.
  • Filter the result table, copy visible rows, or download the complete filtered result as CSV.
